# Correctif cohérence Potentiel d’épargne

Finances et Potentiel d’épargne utilisent désormais exactement les mêmes paramètres :
- compte courant et compte d’épargne ;
- seuil de sécurité ;
- catégorie ou revenus mariages comme revenu principal ;
- proposition le jour du revenu ou le lendemain ;
- décisions déjà enregistrées.

Aucune migration SQL supplémentaire.
